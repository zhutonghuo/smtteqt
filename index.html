🔍 排查「EQuake 一直显示罗蒙诺索夫海岭 / 不画震中X」：这通常是 EQuake 没有拿到有效数据（它显示了内置演示位置）。步骤： ① 确认 EQuake 数据源地址与页顶订阅地址完全一致（http 开头、不要空格、不要 https）； ② 先点「发布到服务器」，等 1~2 秒再看 EQuake； ③ 点「服务器日志」：没有任何 EQuake 请求记录 = 地址/端口不通；有记录但仍不显示 = 点「载入示例报文」发布一条与官方示例完全一致的报文做对照，再不行把日志内容发我。

1 启动服务器

双击 startserver.bat（或 启动服务器.bat），会开一个小窗口并在本机起一个零依赖的 Node 服务，默认端口 8790；端口被占用就自动顺延到下一个。浏览器打开页顶显示的那个地址（一般是 http://127.0.0.1:8790/）。

顶栏「服务器」前面的小圆点 变绿 = 页面连上服务器了；灰点就是还没连上（此时点「📤 发布到服务器」会提示，也可以点「设置服务器」手动填地址）。

2 把订阅地址填给 EQuake

页顶那一长串「EQuake 订阅地址（每秒轮询）」（点一下可以复制）就是给 EQuake 填的本地源地址，通常形如 http://127.0.0.1:8790/json。在 EQuake 的数据源设置里原样粘贴（http 开头、末尾不要空格、不要 https、不要多带路径）。

注意：EQuake 每秒只来拉一次数据，所以「发布」最迟 1~2 秒后才能在 EQuake 里看到。发布后看顶栏「EQuake 取数」，显示 ✓ 正在取数 就说明链路是通的。

3 填一张报文卡并发出去

  • 在卡片区把 震级 / 震中经纬度 / 深度 / 最大震度 填好，点 📍 地图选点 可以在地图上点震中（自动换算成 WGS-84 写回卡片）。
  • 顶栏时刻时区保持默认 UTC+9 —— EQuake 按日本时间解读报文时刻，选 UTC+8 会被当成地震早了 1 小时而整条丢弃。
  • 点 📤 发布到服务器 → 等 1~2 秒 → 看 EQuake。

4 想发多报（速报 → 最终报告 → 取消报）

点 ＋ 添加一报，新卡会自动沿用上一张的 eventID 并把报数 +1；每卡填「距上一报延迟（秒）」，勾上工具栏「⏱ 按延迟逐条投递」，再一次性发布，就会按间隔逐条送出去。
想更省事：先在卡片区填好最终报那张卡，再点「🎲 生成多报序列 → 生成到卡片区」，会自动串出一条由弱到强的序列。

最小可用套路：「载入示例报文」→「📤 发布到服务器」→ 看 EQuake 出图，之后照着改数就行。

一张报文卡里有什么

字段怎么填
eventID 事件ID同一批报必须一模一样，EQuake 才认作「同一次地震」。「＋添加一报」会自动沿用；卡里的「换一个」会把同编号的所有报一起换（不想拆批就别单独改）
reportNum 第几报必须递增。报数相同、或比已经发过的报数小，后面的报会被 EQuake 直接忽略 —— 这是「后面的报发不出来」最常见的原因
reportTime / shockTime发布时刻 / 发震时刻，各自独立填写，互不相干、也不会自动每秒跳。都填 UTC+9 时间文本，点「现在」取本机当前（按上面选的时区）
waveStart 震波已发出(秒)发震时刻比发布时刻早多少 = 波已经往外跑了一段
maxIntensity / maxLgInt最大震度 / 长周期地震动等级，三档见第 6 节
maxIntensity 旁的「不明」只在等 EQuake 自己算时选（见 6 节）
距上一报延迟（秒）这一报相对上一张卡晚几秒送到 EQuake；第一张填 0 = 立即发出。EQuake 每秒轮询一次，实际精度约 1 秒

卡片头部的按钮

  • 第 N 报 + 启用：只发勾上「启用」的卡，想留着不发的临时取消勾选即可。
  • EEW 速报 / PLUM / 最终报告 / 📋 正式报 / 取消报：一键把 isCSIS / isPLUM / isFinal / isCancel 勾上（对应 EQuake 里的报种）。其中「📋 正式报」还会按震级+深度算出确定震度、不重发波，卡片头出现蓝色徽标；配合工具栏「完全不画波前」就是没有 P/S 波的正式报（详见第 8 段）。
  • 📐 算震度：按这张卡的震级 + 深度用本项目算法直接算出最大震度与长周期地震动等级填进去——深度越浅震度越大、越深越小（同震级下深源会被明显压低）。
  • 📍 地图选点：弹窗里点地图选震中，自动 GCJ-02↔WGS-84 换算写回经纬度；右上角可切高德卫星 / OpenStreetMap 备用；下面一排是快捷城市。地图加载不出来（离线）就直接手输经纬度。
  • 删除：删掉这张卡，其余卡的报数会自动理顺。
地震波怎么扩：看卡片底部的「波从震中重新发出」—— 勾上（默认）= 送达时把发震时刻改写成送达时刻，波从震中刚出发，EQuake 里能看见波一圈圈往外扩； 取消 + 填「震波已发出(秒)」= 按这个头程重发（波已向外扩出相应距离）； 都留空 = 继着上一报的波继续扩（速报/PLUM 默认重发，最终报告/取消报默认沿用）。

🎲 生成多报序列（在卡片区上一条虚线框里）

先在卡片区填好最终报（震级/震中/深度/震度设成最终想要的），再点「生成到卡片区」，会自动铺出一串由弱到强、数值来回飘的报，末报 = 你填的最终报。

  • 报数 / 间隔：「大约」在你填的数附近随机浮动，「精确」严格照执行。
  • 震度来源：本项目算法算 / 由最终值往回递减 / 交给 EQuake 计算（置空并自动勾 isCSIS）/ 直接填「不明」。
  • 波程：整条序列每报的地震波起点怎么变——保持稳定（首报锚定、后续报波继着上一次继续扩）/ 每报从震中重发（每报都从原点重扩一遍）/ 随机跳动（后续报约四成从震中重发、其余带上随机「震波已发出秒数」，波前忽近忽远，就是 EQuake 里「变来变去」的效果）。想看波来回跳就选它。
  • eventID / sourceName：两框留空 = 沿用卡片区最终报那张；填了就整条序列统一用它（同一 eventID 才串得起来；信息源建议 JMA / CENC / USGS / CEIC / FJ / TW / KMA / PTWC）。
  • 「↺ 同步」把第一张卡的 eventID 填进来；「🎲 换一个」随机换新编号（同编号的一起换）。

🎯 历史地震预设（再上一条虚线框）

  • 📥 直接填入单卡：把选中的那条预设（震中/震级/深度/震度/发震时刻）填进现有那张卡。
  • 🎲 按此生成多报：把它当作末报的最终值，跑一遍生成整条序列。
  • ✏️ 编辑所选预设：打开预设编辑弹窗。里面带一块内联地图，点地图（或快捷城市、或「⇄ 用页面上最新的报」）直接写回上面的纬度/经度；底部状态行会显示这条存没存过 / 有没有没保存的改动，保存时还会列出「旧值 → 新值」改动清单；有改动直接关窗口或按 Esc 会拦一下。内置历史地震只能另存为自定义后改，不会动原件。
  • 你自己存的预设保存在浏览器 localStorage（键 eqsender.qp.custom），刷新、重开页面都还在；「＋ 新建一条」从空白开始造。
历史发震时刻：默认勾「波从震中重新发出」，因为 1975 年的地震波早就跑完了，用历史时刻发过去 EQuake 屏幕上会是一片空白。想真实复现「波已传遍全球」，就把这个勾取消并填「震波已发出(秒)」。

分页栏（一次备好几场「地震」）

顶上那排 [地震 1] [地震 2] … [＋] 就是分页：每一页是独立的卡片区、独立的 eventID、独立的多报参数，互不干扰。可以一边备着「日本海沟」一边备「台湾以东海域」。

  • 点标签切页；页上的 发布 按钮只发这一页；页名双击可改名；✕ 删掉这一页。
  • 所有改动 800 毫秒后自动存进 localStorage（工具栏「💾 保存工作区」是手动强制存一次；「saveHint」会提示存没存）。

📂 工作区（本地存档管理）

  • 列出你存过的每一场地震分页，可以载回当前页继续编辑、改名、复制成一页新的、从存档删掉。
  • 📤 复制全部 JSON：把整份工作区复制走（备份 / 换电脑）；📥 导入并覆盖存档：把粘进来的内容覆盖回本地存档。
  • 🧹 清除存档：删掉本地存档，下次打开回到空白的「地震 1」。
浏览器清缓存 / 换浏览器会带着存档一起没，重要的整份 → 用「📤 复制全部 JSON」存一份。

EQuake 侧怎么接

  1. EQuake 里把本地数据源地址设成页顶那个订阅地址（http://127.0.0.1:8790/json），http 开头、不要空格、不要 https。
  2. EQuake 保持开着，它会每秒来拉一次。
  3. 回本页点 📤 发布到服务器，等 1~2 秒再看 EQuake 主界面。

三个能一眼看出链路通不通的地方

  • 顶栏「EQuake 取数」：✓ 正在取数（N 秒前）= 通；⚠ 已 N 秒没取数 = EQuake 卡住或地址不对；✗ 没在取数 = EQuake 没开 / 地址没设成本机地址。超过 30 秒没动会标红。
  • 工具栏「本机现在」：跟卡片里的时刻对一下，差 1 小时就是时区选错了。
  • 服务器日志（点「服务器日志」展开）：里面有没有 EQuake 的请求记录 = 端口通不通。

规则速查（来自 EQuake 的报文字段规则）

① 最大震度 / 长周期地震动，三个档位：

档位怎么填
具体值直接告诉 EQuake 是多少级
不明填字面值「不明」；isCSIS=false 且震级 ≤1.0 时 EQuake 会判成 IPF 单点
EQuake 计算 （默认这一档）两个字段置空并自动勾上 isCSIS=true —— EQuake 官方说明：只有 isCSIS=true 且两字段置空才会自行推算烈度；只置空不勾 isCSIS 会显示成「不明」

② 时间是 UTC+9。JMA 24 小时制那一档（凌晨 0 点写成 24/25 时）需要你手动改时间文本。

③ 同一批报必须共用一个 eventID 且报数递增。「＋添加一报」已经帮你做好，「换一个」会整批一起换。

④ 地图选点用的是高德瓦片（GCJ-02 加密坐标），已自动和报文用的 WGS-84 双向换算；高德对日本境外部分海域没覆盖，弹窗右上角切「OpenStreetMap 备用」。

⑤ EQuake 里的「P 波 / S 波」是推算震源的波前，跟报文报种无关，由 EQuake 设置项「隐藏推算震源P/S波」控制，默认显示。想发没有波前的正式报，见第 8 段（卡片「📋 正式报」＋工具栏关波前）。

⑥ 典型发报节奏：速报 → N 秒后最终报告 → 再 N 秒后取消报，三者共用一个 eventID、报数依次 +1。

📋 正式报（没有 P/S 波的确定报）

普通 EEW 速报在 EQuake 里会画一圈一圈向外扩的 P 波 / S 波波前；正式报（确定报 / 地震情報）是震后把震源、震级、最大震度都定下来的报，不画波前，只显示确定的结果。这一节说明怎么在本发报台里发出这种报。

先说清楚一个技术事实：EQuake 的「自定义预警源」（也就是你在设置里填的 http://127.0.0.1:8790/json）只有 EEW 一条通道，官方给的报文模板里也只有 isCSIS / isPLUM / isFinal / isCancel 这几个报种。EQuake 里那些真正叫「地震情報」的正式报（reportJMA / reportUSGS / reportCENC 等）是软件自己从各机构 API 拉的，不能由自定义源注入。所以这里的做法是等效组合：报种发「最終報」＋把 EQuake 的波前显示关掉，视觉效果与正式报一致。

两步走

  1. 卡片上点「📋 正式报」（卡片头部那一排报种按钮里）。它一键做成 isFinal=true（最終報）、按震级+深度算出确定震度填进 maxIntensity / maxLgInt（不置空、不勾 isCSIS，否则 EQuake 会按「不明」处理）、不勾「波从震中重新发出」、清空「震波已发出秒数」。卡片头会出现蓝色「📋 正式报」徽标。
  2. 工具栏「📋 正式报 / P/S 波」下拉选「完全不画波前（正式报）」。它会直接改 EQuake 的 Settings.ini（首次自动备份成 Settings.ini.bak，选回「显示波前（默认）」即可恢复）。改完必须完全退出 EQuake 再重新打开才生效；若 EQuake 还开着就改，它退出时可能把设置覆盖回去。

然后正常点「📤 发布到服务器」，EQuake 里就是一张没有 P/S 波前、带确定震度的正式报。

三档设置分别是什么

档位改动的 EQuake 设置效果
显示波前（默认）隐藏推算震源波=false、检测网格=true、震源推算=trueEEW 原样，波前正常向外扩
只隐藏推算震源 P/S 波隐藏推算震源波=true不画软件自己推算出来的那套波前，其余保留
完全不画波前（正式报）隐藏推算震源波=true、检测网格=false、震源推算=false任何波前都不画，适合发正式报
为什么波前跟报种无关？EQuake 的 P/S 波是「推算震源」画出来的（设置项「隐藏推算震源P/S波」，配置键 IsHidePSWaveOfEstimatedEpicenter），默认显示，跟这条报是速报还是最終報没有关系。所以想「发一张不画波的报」，光改报文没用，必须动这个设置——这也是本仓库里 关闭推算震源.bat / 恢复PS波显示.bat 那两个脚本做的事，现在已集成进页面，不用再单独跑 bat。

常见问题

  • 下拉是灰的 / 显示「服务器不支持」 → 服务器是旧版：重启 startserver.bat（server.js 更新后必须重启）再点 ↻。
  • 提示找不到 Settings.ini → EQuake 至少要先启动过一次，才会生成 %APPDATA%\EQuake\config\Settings.ini。
  • 改了却还在画波 → 没重启 EQuake；或 EQuake 还开着时改的、被它覆盖回去了。选回「显示波前」→ 完全退出 EQuake → 重新打开 → 再选「完全不画波前」→ 再重启一次。
  • 想还原 → 下拉选「显示波前（默认）」；或手动把 Settings.ini.bak 复制回 Settings.ini。

❓ 常见问题

Q1. 发布成功了，EQuake 一直不显示（老是罗蒙诺索夫海岭 / 不画震中）

99% 是 EQuake 没拿到有效数据，它显示了内置演示位置。按顺序查：

  1. EQuake 里的数据源地址与页顶订阅地址完全一致（http 开头、不要空格、不要 https）。
  2. 先点「📤 发布到服务器」，等 1~2 秒再看 EQuake。
  3. 看顶栏「EQuake 取数」是不是 ✓；再看点开的「服务器日志」——一条请求记录都没有 = 地址/端口不通；有记录但仍不显示 = 点「载入示例报文」发一条与官方示例一致的作对照，还不行就把日志内容发出来。
  4. 时区对不上（选了 UTC+8）会让整条报被 EQuake 判为过期而丢掉。

Q2. 只发了前两报，后面的报发不出来

  • 报数没递增 / 重复了 → 检查每张卡的 reportNum，保证 1、2、3… 严格递增；同 eventID 下报数相同会被当成同一报丢弃。
  • 卡片「启用」被取消勾选 → 发布时只发勾上的卡。
  • 多条报用了不同的 eventID → EQuake 当成两次地震，第二次会被忽略。

Q3. 地图点不出来 / 一片空白

Leaflet 走 CDN，断网就加载不出来：弹窗会显示「地图组件加载失败」的提示框，此时直接手输经纬度，或用下面的快捷城市按钮；联网后重开弹窗即可。

Q4. 刷新页面 / 重启服务器后，之前发的地震没了

「本次服务器已发出的地震」这块是服务器内存里的，服务器重启或页面刷新后清空，属于正常；要接着对同一事件加报，重新填好卡片再发布即可（报数要接着往上加）。本地存档不受影响，还在 localStorage 里，打开后自动恢复。

Q5. 想取消已经发出去的地震

在「本次服务器已发出的地震」里找到那条 → 点取消（发一张 isCancel 的报，同一个 eventID、报数 +1）。
