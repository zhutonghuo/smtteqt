🎲 生成多报序列 共 报 每报间隔 秒 先在上方卡片区填好最终报（震级/震中/深度/震度/类型设成最终想要的，并勾好「波从震中重新发出」），点这里自动生成一串由弱到强、数值来回飘的报，末报=你填的最终报； 「大约」会在你填的数附近随机浮动（报数、间隔都飘忽），「精确」则严格按你填的执行；生成后可逐张微调再发布。
规则说明（来自 EQuake）： ① maxIntensity / maxLgInt 三个档位：「具体值」（直接告诉 EQuake）、「不明」（EQuake 显示「不明」）、「EQuake 计算」（字段留空，由 EQuake 根据震级与震中距自行推算震度，不依赖 isCSIS，**默认就是这一档**）；勾选 isCSIS 也会把两字段输出为空； ② isCSIS 不勾、震度为「不明」且震级 ≤ 1.0 时，EQuake 自动判为 IPF 单点； ③ 时间按 UTC+9 填写；若需 JMA 24+ 时制（如凌晨 0 点写成 24/25 时），请手动修改时间文本；地震波控制（同一 eventID 的续报/加报默认「继着上一次波」、不重置）：勾「波从震中重新发出」= 送达时把发震时刻改写成送达时刻，波从震中刚出发；或填「震波已发出(秒)」= 送达时按此头程重发（波已向外扩约 秒×7km，不继着上一次）；两者都留空 = 沿用该事件已建立的震源时刻，波接着上一报继续向外扩（速报/PLUM 默认勾选重新发出；最终报告/取消报默认不勾，继着上波）； ④ 底图为高德瓦片（GCJ-02 加密坐标），页面已自动与报文使用的 WGS-84 互转；高德对日本等境外海域无覆盖，可在地图右上角切到「OpenStreetMap 备用」； ⑤ 「距上一报延迟」= 该报相对前一报晚多少秒送到 EQuake（EQuake 每秒轮询一次，实际精度约 1 秒）；第 1 报延迟填 0 即立即发出；典型用法：速报 → N 秒后最终报告 → 再 N 秒后取消报，共用一个 eventID； ⑥ EQuake 的「P 波 / S 波」是**推算震源**的波前，与报文类型无关，受软件设置「隐藏推算震源P/S波」（配置键 IsHidePSWaveOfEstimatedEpicenter）控制，默认会显示。
🔍 排查「EQuake 一直显示罗蒙诺索夫海岭 / 不画震中X」：这通常是 EQuake 没有拿到有效数据（它显示了内置演示位置）。步骤： ① 确认 EQuake 数据源地址与页顶订阅地址完全一致（http 开头、不要空格、不要 https）； ② 先点「发布到服务器」，等 1~2 秒再看 EQuake； ③ 点「服务器日志」：没有任何 EQuake 请求记录 = 地址/端口不通；有记录但仍不显示 = 点「载入示例报文」发布一条与官方示例完全一致的报文做对照，再不行把日志内容发我。
